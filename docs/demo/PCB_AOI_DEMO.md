# QualityPilot 固定演示：AOI 短路报点复核

文档编号：QP-DEMO-001
性质：合成演示资料，不是企业作业指导书，不包含真实生产批次数据。

## 观察与结论
AOI 短路报点增加仅说明检测系统发现了更多疑似异常，不能据此认定真实短路增加，也不能确认具体根因。

## 建议的复核顺序
1. 保存 AOI 原始图像、程序版本、检测窗口与报点位置，并记录时间范围。
2. 用良品图和人工复核检查光源、曝光及反光，区分疑似误报与连续金属连接。
3. 对同一件样品进行显微复核与电气测试，核对样品编号、测试覆盖范围和时间。
4. 证据相互冲突时保留两份结果，标记待复核，不能直接判定其中一份错误。

## 缺失数据与操作边界
没有 MES、Gerber 或现场复核数据时，将这些资料列为待补充，不声称已经查询或获取。
补充资料不应阻断现有原图与人工复核。不要直接放宽检测阈值或修改生产参数。
任何调整建议都应经过工程评审、样板验证和人工审批。
