# QualityPilot 项目状态

最后更新：2026-08-01

## 当前架构

- PostgreSQL 17 与 pgvector 通过项目根目录的 `compose.yaml` 配置。
- 数据库数据保存在命名卷 `qualitypilot_pgdata` 中。
- FastAPI 后端位于 `backend/`，使用 Python 3.12、异步 SQLAlchemy、asyncpg 和 Pydantic Settings。
- 本地后端虚拟环境位于 `backend/.venv`。
- 后端运行时，开发环境 API 文档地址为 `http://localhost:8000/docs`。
- `frontend/`、`data/` 和项目根目录的 `tests/` 尚无实际实现。
- 项目已于 2026-08-01 初始化 Git，默认分支为 `main`，并连接到 GitHub 私有仓库 `csclly/qualitypilot`。

## 已完成功能

- FastAPI 应用启动与关闭生命周期。
- 用于本地前端开发的 CORS 配置。
- `GET /` 服务信息接口。
- `GET /api/v1/health` 进程健康检查接口。
- `GET /api/v1/ready` 数据库就绪检查接口。
- `POST /api/v1/knowledge/documents` 知识文档元数据新增接口。
- `GET /api/v1/knowledge/documents` 知识文档列表接口。
- PostgreSQL 异步连接与会话管理。
- 本地开发环境启动时创建 pgvector 扩展和初始 SQLAlchemy 数据表。
- `knowledge_documents` 模型，包含标题、来源、状态和时间字段。
- `knowledge_document_chunks` 模型，包含有序文本分块、文档外键、级联删除关系，以及可空的 `vector(1536)` 嵌入字段。

用户此前已经成功验证健康检查、就绪检查、文档新增和文档查询接口。在 2026-08-01 的项目检查过程中，当前执行环境无法连接 Docker Desktop，端口 5432 和 8000 也未监听，因此该次检查没有独立复核实时容器状态和实际数据库结构。

## 已知缺口

- 尚无文件上传接口。
- 尚无文档解析器和文本切分服务。
- 尚无将文档分块写入数据库的完整导入流程。
- 尚未保存原始文件名、MIME 类型、文件大小、校验值、存储路径、解析器信息、处理错误和分块数量等文件元数据。
- 尚未保存分块位置、页码、长度和解析元数据。
- 数据库结构演进仍依赖 `create_all()`，尚未引入 Alembic。
- 尚无自动化测试套件。
- 文档列表尚未分页。
- 尚未选定嵌入模型，因此当前应保持嵌入字段为空。

## 下一里程碑：文件导入

按照以下顺序实现文件上传、文本提取、自动切分和分块事务写入：

1. 检查实际运行数据库的结构和已有数据。
2. 引入 Alembic，并建立与现有数据库结构一致的基线；不得重建数据库。
3. 通过增量迁移增加文档文件元数据和处理状态字段。
4. 增加用于追溯来源的分块位置、页码和元数据字段。
5. 增加可配置的上传文件存储和安全校验。
6. 增加 multipart 文件上传接口，第一阶段支持 TXT、Markdown、PDF 和 DOCX。
7. 实现解析器适配层，输出带来源信息的标准化文本块。
8. 实现适合中文文本、能够识别段落和句子边界，并支持分块大小与重叠配置的切分器。
9. 在单个事务中写入一份文档的全部分块；成功后将文档设为 `ready`，失败时设为 `failed`。
10. 增加文档详情和文档分块查询接口。
11. 增加单元测试、API 测试和 PostgreSQL 集成测试，包括回滚和损坏文件场景。

## 初步实施决策

- 第一阶段使用有文件大小限制的同步导入；需要处理大文件或并发任务时，再引入持久化任务队列。
- 原始文件使用生成的名称保存在可配置上传目录中；文件元数据和解析后的文本分块写入 PostgreSQL。
- 使用 SHA-256 校验值支持文件追溯和可选的重复检测。
- 文档状态统一使用 `created`、`processing`、`ready` 和 `failed`。
- 中文文本先按照结构和句子边界切分，再应用最大长度限制，并保留重叠内容、页码和偏移位置。
- 本里程碑不生成嵌入向量。必须先选定并固定嵌入模型，之后才能确定向量生成逻辑或调整向量维度。

## 安全约束

- 不得删除或重建数据库及其 Docker 数据卷。
- 不得运行 `docker compose down -v`。
- 在对照实际数据库结构审查生成的迁移之前，不得执行结构变更。
- 不得暴露 `.env` 的值或提交密钥。
