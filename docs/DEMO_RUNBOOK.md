# QualityPilot 固定演示流程

目标：在约 8—10 分钟内展示“知识 → 证据 → 草稿 → 人工复核 → 状态恢复”。这是演示节奏安排，不是系统性能指标。所有演示问题和资料均明确标记为合成测试，不代表现场质量判定。

## 演示前准备

1. 按根 README 启动 PostgreSQL、后端和前端，打开 http://localhost:5173。
2. 如展示模型分析，按 SELF_HOSTED_QWEN.md 启动云端 Uvicorn、配置 PCB_LLM_API_KEY，并保持 SSH 隧道。
3. 检查“数据库已连接”。它只证明数据库就绪，不证明生成模型或 Embedding 可用。
4. 准备本目录下的 [演示资料](demo/PCB_AOI_DEMO.md)。首次上传需要百炼 Embedding；已经导入则复用已有文档，不反复上传。
5. 本地默认允许填写未认证复核人，仅适合开发演示。开启强制认证时应使用有审批权限的凭据，不通过关闭认证解决演示问题。

固定问题：

> 【固定演示】AOI短路报点增加，没有MES和Gerber数据，应先复核什么，哪些结论目前不能确认？

## 演示步骤

| 时间安排 | 操作 | 讲解与观察点 |
| --- | --- | --- |
| 0—1 分钟 | 简介三个页面 | 质量分析、知识库、证据检索；生成结果需要人工复核 |
| 1—3 分钟 | 知识库上传 PCB_AOI_DEMO.md，标题填写“QualityPilot 固定演示资料” | 展示入库状态、原文分块与向量信息；不得将上传中说成入库成功 |
| 3—4 分钟 | 证据检索选择关键词，输入固定问题，查看最多 5 条结果 | 展开原文，说明匹配分不是正确率；结果依赖整个库，不承诺某文档必排第一 |
| 4—6 分钟 | 点击“用此问题创建分析”，确认关键词检索、证据上限 3，选择规则草稿 | 演示云端生成停机时仍可整理证据；新分析会重新检索 |
| 6—7 分钟 | 查看摘要、建议、风险，点击引用原文 | 区分观察事实、待验证假设和缺失资料 |
| 7—8 分钟 | 拒绝这条演示草稿；复核人填写 demo-reviewer，备注“固定演示流程验证，不作为生产处置依据” | 确认复核勾选后提交，查看审批事件；不要操作其他人的运行 |
| 8—9 分钟 | 刷新页面，再用完整链接或运行编号找回 | 状态来自后端持久化；最近记录只属于当前浏览器 |
| 9—10 分钟 | 选择模型分析，新建同一问题的运行 | 检查是否显示“模型生成”；如降级则展示真实错误，不宣称模型生成成功 |

有时间可将检索方式改为混合检索，再新建一条分析，说明 Embedding 与生成模型是两个独立服务。不要反复点击长请求按钮。

## 通过标准

- 文档实际入库且原文可查看，检索确有结果。
- 规则草稿与模型草稿标识清楚，引用能定位到本次证据。
- 演示记录拒绝后刷新仍为拒绝，审计身份及备注可读回。
- 模型分支只有 generation_mode=model 才记为生成接入通过。
- 演示完成不代表模型建议可直接用于生产，不代表所有问题都能通过模型契约。

## 常见现场问题

| 现象 | 处理 |
| --- | --- |
| 数据库未连接 | 检查本地数据库和后端 ready；不用删除数据卷 |
| 上传或混合检索失败 | 检查百炼 Embedding 配置与服务，不盲目重启生成模型 |
| 云端连接重置 | 确认 Uvicorn 在 8001 持续监听，再检查 SSH 隧道 |
| 401 Invalid API key | 同一终端设置 PCB_LLM_API_KEY 后重启云端进程，与本地 GENERATION_API_KEY 对齐 |
| HTTP 200 但草稿降级 | 检查结构化字段、编号和响应格式；HTTP 成功不等于草稿合法 |
| 模型建议偏题或引用薄弱 | 保留草稿并拒绝或待复核，作为评测失败案例；不修改结果伪装演示成功 |
| 审批结果不明确 | 先刷新状态，避免直接新建一个相反决定 |

## 演示后的证据

记录实际运行编号、截图、生成模式和审批结果。演示记录与审计保留；本手册不提供删除或重置数据库操作。最新实际演示结果见项目状态。
